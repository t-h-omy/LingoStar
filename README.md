# ⭐ LingoStar ⭐

A fun Progressive Web App for 6th graders to practice English irregular verbs!

![LingoStar Banner](https://github.com/user-attachments/assets/ff7a2f5e-bd91-4224-a52a-f320e9f72a44)

## 🌟 Features

### 📚 Learning System
- **49 Irregular Verbs** with past simple forms and Spanish translations
- **Star Progression**: outline → yellow → pink → blue → purple → gold
- Earn stars with correct answers, lose stars with repeated mistakes
- **Progress Tracking** - See your mastery level for each verb

### 🎮 4 Exercise Types
1. **🎯 Multiple Choice** - Select the correct past simple form
2. **✏️ Type the Answer** - Type the past simple form
3. **🌍 Translation** - Match verbs to Spanish meanings
4. **📝 Fill the Gap** - Complete sentences with past simple

### 🎨 Kid-Friendly Design
- Colorful purple gradient theme
- Fun emoji icons
- Smooth animations (bounce for correct, shake for incorrect)
- Sound effects for feedback
- Responsive design for all devices

### 💾 Smart Features
- **LocalStorage** - Progress saved automatically
- **PWA** - Install on mobile devices
- **Offline Support** - Works without internet
- **No Login Required** - Start learning immediately

## 🚀 Quick Start

### Option 1: Use GitHub Pages
Visit: `https://t-h-omy.github.io/LingoStar/`

### Option 2: Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/t-h-omy/LingoStar.git
   cd LingoStar
   ```

2. Open with a local server:
   ```bash
   # Python 3
   python3 -m http.server 8080
   
   # Or Python 2
   python -m SimpleHTTPServer 8080
   
   # Or Node.js (with http-server)
   npx http-server
   ```

3. Open your browser to `http://localhost:8080`

### Option 3: Just Open the File
Simply open `index.html` in your web browser!

## 📱 Install as PWA

On mobile devices:
1. Open LingoStar in your browser
2. Tap the "Add to Home Screen" option
3. Access the app like a native application!

## 🎯 How to Use

1. **Choose an Exercise** - Select from 4 different exercise types
2. **Answer Questions** - Practice irregular verbs
3. **Earn Stars** - Progress through 6 star levels
4. **Track Progress** - View your mastery in "My Progress"
5. **Keep Learning** - Your progress is saved automatically!

## 🏗️ Technical Details

- **Pure HTML5, CSS3, Vanilla JavaScript** - No frameworks needed
- **Progressive Web App** - Manifest and Service Worker included
- **Responsive Design** - Works on desktop and mobile
- **Web Audio API** - For sound effects
- **LocalStorage API** - For progress persistence
- **Service Worker** - For offline functionality and caching
